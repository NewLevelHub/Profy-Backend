- **Care и Dev остаются раздельными** (ключевая развилка «лечить vs учить»).

## Формула апдейта (вид решён, числа — калибровка)
- match(ответ, лист) = Σ_ось вклад[ось] · профиль[ось].
- `log belief(L) += β · match`, затем softmax (Σ belief = 1). Старт β ≈ 0.7.
- Выбор вопроса: минимизировать ожидаемую энтропию belief. Та же match-функция.
- «не знаю» → вклад 0.
- RIASEC-fix держится: нормировка по листьям, не по осям.

## Остановка (форма решена, числа — калибровка)
- Одна профессия, если top-1 > T И top-1 ≥ M × top-2. Старт: T ≈ 0.45, M ≈ 1.5.
- Иначе кластер top-k (k ≤ 3). Кластер — валидный исход, не провал.
- Потолок вопросов по возрасту — предохранитель (junior ниже). Упор в потолок → кластер.

## Правило формата
A, E → прямой. D → ситуативный. B, C → смешанный (наверху прямой, на развилках ситуативный). Глубина 0–1 → только прямые.

## Правило старта (анти-жадность)
Первые ~3 вопроса — широкие прямые по разным семействам, не углубляя первый ответ. Ситуации с глубины 2.
