# Telegram для специалиста — контракт API

Бот присылает психологу напоминания о созвонах — за сутки и за час — и
пятничное «заполните расписание на следующую неделю» вместе с письмом
(`app/services/telegram/`). Пока бот не настроен (`TELEGRAM_BOT_TOKEN`,
`TELEGRAM_BOT_USERNAME`, `TELEGRAM_WEBHOOK_SECRET` пустые), всё выключено.

Все адреса — под `/api/v1/telegram`, роль `psychologist`.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/me` | `{enabled, linked, linked_at}`. `enabled: false` — карточку не показывать |
| POST | `/me/link` | `{url}` — одноразовая ссылка `https://t.me/<бот>?start=<код>`, действует 30 минут; новая отменяет прежнюю |
| DELETE | `/me` | отключить Telegram, `204` |

При выключенном боте `POST /me/link` и `DELETE /me` — `404 telegram_disabled`.

**Подключение.** Профиль открывает `url` в новой вкладке, специалист жмёт
«Старт» в Telegram, бот отвечает «Готово». Профиль перечитывает `GET /me`
(например, когда вкладка снова в фокусе). `/stop` в чате с ботом тоже
отключает.

**Напоминания.** Созвоны специалиста в статусе «ожидает» или «подтверждена»:
«Напоминание: …» — когда до начала от 1 до 24 часов, «Через час, …» — меньше
часа. Каждое — один раз на созвон; перенесённый созвон — новый, напомнится
заново. Если специалист заблокировал бота, связь снимается.

**Расписание.** Когда приходит письмо «Заполните расписание на следующую
неделю» (день и время — в настройках владельца, по умолчанию пятница 18:00),
то же сообщение с кнопкой «Перейти в «Расписание»» уходит в Telegram.
**Отчёт ждёт проверки.** Вместе с письмом «Новый отчёт ждёт проверки» — то же
в Telegram с кнопкой «Перейти к отчёту»; при тарифе с созвонами — с припиской,
что опубликовать можно после второго созвона. Получатель (и письма тоже) —
психолог последней сделки ученика; ученик без сделки — все его психологи.

Под напоминанием о созвоне — кнопка «Перейти в «Созвоны»». Локально кнопка
ведёт на `127.0.0.1` вместо `localhost`: на `localhost` Telegram кнопку не
принимает (Profile нужно запускать с `npm run dev -- --host 127.0.0.1`).

**Webhook** `POST /webhook` — только для Telegram, с заголовком
`X-Telegram-Bot-Api-Secret-Token`; включается `scripts/telegram_set_webhook.py`.

**Локально** вебхук невозможен (Telegram ходит только на публичный HTTPS).
Вместо него: `docker compose exec api python scripts/telegram_poll.py` —
забирает сообщения бота (`getUpdates`) и раз в минуту проверяет напоминания.
