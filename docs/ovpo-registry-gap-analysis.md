# Сверка University с официальным реестром ОВПО (2026-08-19)

Источник: приложение к `_СПИСОК_ОБЛАДАТЕЛЕЙ_ОБРАЗОВАТЕЛЬНЫХ_ГРАНТОВ_НА_2026_2027_УЧЕБНЫЙ.pdf` (МОН РК) — та же PDF, из которой уже взяты `admission_scores_2026`/`min_ent_threshold` для 517 программ. Транскрибировано в `scripts/data/ovpo_registry_2026.json` (90 кодов, код → полное название → сокращение). Это официальный список ВСЕХ вузов, участвующих в грантовом конкурсе — то есть canonical-справочник для дедупликации и мэтчинга, надёжнее любого стороннего сайта.

Сверка выполнена скриптом (одноразовый прогон, не сохранён как management-скрипт) против всех 64 строк `University` с `country = 'Казахстан'`.

## Результат

- **Точное совпадение по названию/сокращению: 31 из 64** — этим 31 вузу можно сразу проставить `ovpo_code` без вопросов.
- **Ещё ~12 совпадений находятся вручную** (автоматический fuzzy-мэтч по строкам даёт слишком много ложных срабатываний — например "Satbayev University" и "SDU University" получают высокий score, хотя это разные вузы; доверять авто-fuzzy нельзя, нужен списочный человеческий/LLM-review одной строки на пару):
  - `akademiya-logistiki-i-transporta` → 019 (ALT University)
  - `cardiff-kazakhstan` → 535 (Cardiff University Kazakhstan)
  - `akademiya-kajnar` → 089 (Q University)
  - `akademiya-grazhdanskoj-aviaczii` → 157 (Академия Гражданской авиации)
  - `kazahskaya-akademiya-sporta-i-turizma` → 020 (Казахская академия спорта и туризма)
  - `kaspijskij-universitet` → 079 (Каспийский общественный университет) — **проверить**, не совпадает ли это с 003 (Yessenov/КУТИЕсенова) — возможен дубль
  - `kostanay-regional-university` → 036 (Костанайский региональный университет им. Байтурсынулы)
  - `mezhdunarodnaya-obrazovatelnaya-korporacziya` → 022 (МОК)
  - `toraigyrov-university` → 038 (Торайгыров университет)
  - `universitet-mezhdunarodnogo-biznesa-uib` → 069 (Университет Международного бизнеса)
  - `karsu-buketova` → 031 (Карагандинский университет им. Букетова — обрати внимание: в реестре это "национальный исследовательский", у нас название короче — вероятно, тот же вуз под старым названием)
  - `kazahskij-gosudarstvennyj-zhenskij-pedagogicheskij-universitet` → 025 (переименован в "национальный женский педагогический" — тот же вуз)

## Найденный конкретный баг: вероятный дубль вуза

`kazatu` (short_name «КазАТУ / КазАТИУ», city **Астана**) и `kazahskij-agrotehnicheskij-universitet-kazatu` (short_name «КазАТУ», city **Алматы**) — оба претендуют на код 002 «Казахский агротехнический исследовательский университет им. Сакена Сейфуллина», который в реальности **один вуз в Астане**. Похоже на дубль строки с ошибочным городом (Алматы) — нужна ручная проверка перед тем, как проставлять `ovpo_code`, иначе код присвоится не той строке.

## Следующий шаг

1. Завести колонку `University.ovpo_code` (unique, nullable) — это заменяет хрупкий мэтчинг по строке имени на канонический ключ для всех будущих обновлений.
2. Применить 31 точное совпадение сразу; 12 ручных — после проверки по списку выше; починить дубль КазАТУ.
3. По списку из 40+ отсутствующих кодов — догрузить вузы+специальности той же схемой, что `almaty_universities_data.py`/`astana_universities_data.py` (ручной/LLM-ресёрч по каждому вузу, не по одному городу зараз, а сразу по всему списку кодов сверху).
4. Тот же реестр разом чинит и проблему п.1 из прошлого анализа («коды есть, вузов с таким названием нет») — теперь известно точно, каких 40+ вузов не хватает, а не «примерно 27 без баллов».
