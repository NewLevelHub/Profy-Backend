## Историческое архитектурное ревью (Backend Architect, 2026-08-04)

Ниже сохранён контекст решения до hard cutover. Рекомендации про dual-run
больше не описывают текущую архитектуру:

1. **Прецедент AKN-021 не был учтён изначально** — репозиторий уже проходил ровно такой переход (блочный движок → осевой), с дискриминатором через наличие строки (`Assessment.is_akinator`) и аддитивными колонками на `Direction`. Добавлена задача #31.
2. **`[GATE] AKN-021`, судя по всему, не сработал** — старые `required_scores`/`bonus_scores` в `Direction` всё ещё живы. `Direction` уже тащит два непогашенных поколения скоринга; без явного gate RIASEC станет третьим. Добавлена задача #35.
3. **#20 изменена**: не поле `holland_code` на `Direction`, а отдельная join-таблица с полем уверенности/происхождения — Holland-код приходит из внешнего датасета с уже известными нестыковками (см. #17), в отличие от родного `profile`.
4. **Нет задачи на in-flight сессии** и **feature-flag на откат** — обе добавлены (#32, #34).
5. **Тестовая усталость школьников** — текущий движок умеет рано останавливаться и адаптирован по возрасту; фиксированный опросник на 148 пунктов такого не умеет. Добавлена задача #33.
