# Психоблок — казахские переводы (staging)

Хранилище kk-переводов, специфичных для психоблока. Пока **не подключено**: на
`pro-282` нет инфраструктуры i18n (нет `app/i18n/catalog/*.py`, колонки `locale`
на `Question`, `react-i18next`, неймспейсов, `i18n:check`). Появится с **PRO-293**
после мёржа KZ-эпика в `pro-282`.

**Процесс.** Тексты ниже — LLM-primary черновик. Вычитка носителем идёт в ветке
локализации (KZ-эпик, сейчас на ревью). Когда PRO-293 заводит каталог/неймспейсы —
эти строки раскладываются по ним 1:1; правки вычитки вносятся сюда же и потом в код.

Разделы повторяют `psych-block-spec.md`: **§A** шкала лжи (PRO-301), **§B**
психоэмоциональный (PRO-310), **§C** МАК (PRO-319).

## §A. Шкала лжи (PRO-301)

### A1. Infrequency-ловушки

`scripts/infrequency_bank.py`. kk-набор = **отдельные строки** `locale='kk'`,
структурно идентичные ru: тот же `key`, `expected_answer`, `validity_role`,
позиция в последовательности. Скоринг (`infrequency_failed`) от языка не зависит —
kk-прохождение при эквивалентных ответах даёт тот же результат.

Требование: ловушка должна оставаться **очевидно** истинной/ложной и на казахском,
без абсурдной комичности.

### A2. 20 пунктов MC-SDS

**НЕ здесь.** Тексты пунктов на экране прохождения — часть аттестованной шкалы,
переводятся общим процессом перевода банков вопросов KZ-эпика (`scripts/
lie_scale_bank.py`, колонка `locale`), так же как Big Five. Этот тикет только
ссылается на соответствующий KZ-тикет.

(`keyed`, `validity_role`, порядок); скоринг на kk-прохождении даёт тот же
`sd_raw`, что на ru при эквивалентных ответах.

### A5. Чек-лист вычитки (AC PRO-301)

- [ ] 5 ловушек: kk-текст очевиден носителю (истина/ложь не спорны), регистр
      как у пунктов Big Five, без комичности.
- [ ] `title` — согласовать термин: «Хаттаманың сенімділігі» vs «Жауаптардың
      сенімділігі» (для школьника понятнее второе).
- [ ] `state.*` — три состояния читаются как в ru; жёлтый = «балл 16+», не
      «слегка повышен».
- [ ] `disclaimer` — «Не заключение» / «Высокий балл не означает ложь»
      сохранены дословно по смыслу.
- [ ] Термины `LongString` / `IRV` / `MC-SDS` — оставить латиницей.
- [ ] После PRO-293: `i18n:check` — паритет ключей `psychValidity` ru↔kk
      зелёный; kk-прохождение даёт тот же `sd_raw`.
